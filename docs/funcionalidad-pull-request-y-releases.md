## PR-02 — Crear Pull Request

- Seleccionar repositorio.
- Seleccionar rama origen.
- Seleccionar rama destino.
- Definir título.
- Definir descripción.
- Asociar Work Items.
- Agregar revisores.
- Crear PR.

- Información general.

## PR-04 — Revisar cambios

- Listar archivos modificados.
- Mostrar diff.
- Mostrar líneas agregadas/eliminadas.
- Navegar entre archivos.
- Agregar comentarios.
- Responder comentarios.
- Resolver comentarios.

## PR-05 — Gestionar aprobación

- Aprobar.
- Solicitar cambios.
- Consultar estado de revisores.
